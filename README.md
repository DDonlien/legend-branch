# Legend Branch / 传说谱系

> Trace the evolution of legends.

LegendBranch 提供随搜索增长的共享知识库，以及从知识谱系基线创建的个人故事项目。传说角色、民俗母题、文学版本、历史事件和现代作品可以放在可探索的时间图谱中，呈现传播、分支、合流和演化；个人项目可以继续添加自己的故事节点与发展关系。

## 项目概述

- 横轴表示时间，以可考证来源或作品出现时间为主要定位依据。
- 纵轴按用户选择的条目标签分组，默认沿用文化 / 地区；每个区块包含若干角色行。
- 节点表示某个角色或概念在特定文化和时代中的一个版本。
- 连线表示来源、影响、改编、合流等关系，并附带可信度和外部来源。
- 用户可以 Trace 一个条目，聚焦查看关联谱系。

## 当前阶段

当前提供数据库时间图谱、通过站内搜索积累的共享知识库，以及无需注册的浏览器个人项目。

P1 只验证一件事：以“孙悟空”为唯一样例时，“横向时间 × 纵向文化区块 × Trace 角色谱系”的核心阅读体验是否清晰、好看，并值得继续扩展。

## P1 核心体验

- 打开页面后默认追踪孙悟空，在图谱与详情中查看追踪中心。
- 在可横向、纵向滚动的主图中查看传播和演化关系。
- 点击节点后在当前页面打开克制的浮层，查看简介、关系和外链。
- 清除 Trace 后查看 P1 中围绕孙悟空整理的全部节点。
- 顶栏在追踪中提供“清除 Trace”；通过条目详情的“Trace 此条目”开始或切换追踪。
- 当前界面采用 Material 3 Expressive，保留顶栏、文化分区、画布和详情浮层结构。
- 分支参考 GitTogether 的轨道，以平滑曲线衔接两处 45° 换道；相邻卡片之间走间隙通道，连线与描边避让大卡片。
- 为现代作品展开非等距时间轴；历史年份不变，时间刻度与文化索引随画布滚动同步。
- 搜索条目或标签，先查看已有结果，再从 Wikidata 联网增补；点击结果查看梗概、标签、关系和来源。
- 点击详情标签可继续探索同类条目。
- 搜索增补后自动刷新共享图谱；可靠年代和文化 / 国家信息齐全的条目进入画布，待定位条目继续保留在搜索中。
- 顶栏搜索位于左侧，最左侧可收起工具栏；收起后通过左上角的小型图标恢复。
- 通过“知识库 / 个人项目”下拉列表切换空间，在独立弹窗中从选中条目及其关联谱系创建项目，编辑故事节点、添加或移除发展关系。
- “分组依据”单选所属国家、文化、类别或主题；“标签”多选该依据下的标签并调整左栏顺序，共享视图和每个项目分别保存偏好。
- “信息密度”提供节点、名称、详细卡片三档。节点模式悬停或键盘聚焦时展开完整卡片，点击仍打开详情；年代与真实关系保持一致。
- 语言菜单切换完整中英文界面，品牌分别显示“传说谱系”或“Legend Branch”。语言和密度随浏览器保存；知识正文、项目名称与用户创作保留原文。

## 技术栈

- TypeScript
- React
- Vite
- 原生 SVG 图谱画布
- Cloudflare Workers + D1 共享知识库
- Google Material Web 2.5.0 标准组件与 Expressive labs，使用 @lit/react 接入
- Google Material Color Utilities / HCT 色彩角色
- 自托管 Roboto Flex 与 Material Symbols Rounded

Expressive 按钮、图标按钮和卡片直接使用官方组件。Material Web 尚无独立 Search bar 元素，顶栏搜索由官方 Filled Text Field 与 Expressive 图标按钮组合，通过组件 token 调整紧凑尺寸。实验组件版本固定，构建适配使用包内官方等价样式。

## 快速开始

```bash
npm install
npm run dev
```

完整搜索流程还需要本地后端。在另一个终端执行：

```bash
npm run build
npm run db:migrate:local
npm run dev:api
```

Vite 开发和预览将 `/api` 转发到 `127.0.0.1:8787`。本地 D1 状态保存在忽略入库的 `.wrangler/`；线上 D1 是全用户共享数据源。本地启动不需要云端登录。

## 增量知识库

条目、来源、梗概版本、标签和关系分别保存。标签是多对多分类，可以同时表达国家和主题；它与传播 / 影响关系不同。实体以稳定外部 ID 去重，共用资料链接的不同文学版本仍然独立。

每次搜索先读取数据库，再联网查询 Wikidata 的结构化实体，保存名称、别名、来源、短梗概及国家 / 类别 / 主题标签。原始数据采用 [Wikidata CC0](https://www.wikidata.org/wiki/Wikidata:Licensing)，Wikipedia 仅提供索引链接。初版来源范围为 Wikidata，不是全网爬虫或 AI 自动撰稿。六小时内相同查询复用已保存结果，随后可再次更新；失败不会删除旧内容。

新来源与梗概版本追加保存，人工整理内容优先显示。联网发现的改编和灵感关系属于待复核候选，不能凭标签相同推断关系。有明确来源和年份精度的年代、文化或国家标签时，条目自动加入图谱；相关端点均可定位时显示真实关系，保留原有可信度和待复核标记。缺少信息的条目仍可在搜索与详情阅读。

图谱通过分页 API 读取共享条目与关系，避免静默截断。结构化年代保存在 `entry_placements`；原样例的年份、角色行和默认 Trace 保留。非等距时间轴可向更早或更晚年代扩展。

## 个人项目空间

选择知识库条目后，打开“知识库 / 个人项目”列表并选择“创建项目”，在独立弹窗中命名，以该条目及其关联谱系创建项目。基线是创建时的独立快照，保留来源和候选状态，不随公共知识库后续更新而改变。项目可以添加、编辑、删除节点，添加或移除有方向的发展关系；个人创作明确标注，年份可暂缺，补全年份后自动入图。

项目保存在当前浏览器、当前站点的本地存储中，无需注册，不上传到共享数据库。刷新和重新打开页面可以继续使用；不同浏览器、设备或域名不会自动同步。空间列表可导入 JSON 备份，选中个人项目后可重命名、导出或删除；清除网站数据前先导出。导入创建新项目，不覆盖已有项目。浏览器存储失败时界面明确提示未保存。

每个标签都有所属分组依据。左栏按单选的依据组织，再多选其下的标签并调整优先顺序；多标签条目归入首个匹配组，其他可定位条目归入“其他标签”。共享视图偏好保存在浏览器，每个项目保存自己的分组设置，均可恢复全部标签。旧项目和备份仍能读取，缺少类别的自定义标签归入主题，旧的混合标签偏好从首个有效标签推定依据，原数据保持兼容。新建故事标签可以选择所属国家、文化、类别或主题。

## Cloudflare 部署

线上入口：[LegendBranch](https://legend-branch.taobe-roshambo.workers.dev/)。当前前端和 API 同域托管在 Cloudflare Workers，知识库保存于 D1。

前端和 API 可通过同一个 Worker 发布，D1 保存全用户共享内容。默认使用 `workers.dev` 地址，不需要购买域名。

```bash
npx wrangler login
npm run deploy
```

`deploy` 会构建应用、应用尚未执行的远端 D1 迁移并发布前端和 API。仓库配置绑定本项目已创建的 D1；在其他 Cloudflare 账号部署时应先创建自己的数据库并替换 `database_id`。`npm run seed:generate` 根据样例导出种子 SQL 至 `output/generated-seed.sql`，供审阅后追加新迁移；已经应用的迁移不要直接修改。

## 产品边界

LegendBranch 可以保存神话、民俗、文学、历史事件和现代作品的来源资料，但不会把未经核验的 AI 推断当作事实发布。图谱显示有来源的年代与文化 / 国家信息，缺失时不编造位置。个人故事属于独立创作空间，与共享知识的事实状态分开。

当前分组入口配置左栏标签；账号、云端个人项目同步和内容审核后台尚未提供。生产构建输出到 `dist/`，可以使用 `npm run preview` 本地查看；共享知识库的存储、数据来源与 API 边界见后端文档。
